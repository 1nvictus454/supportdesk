# Глоссарий

| № | Термин | Определение | Синонимы / не путать с |
|---|--------|-------------|------------------------|
| 1 | Клиент | Пользователь, который обращается в поддержку с проблемой или пожеланием по сервису. | - |
| 2 | Уровень клиента | Категория или статус клиента, определяющий приоритетность его обращений (например, VIP, обычный). | Не путать с Приоритетом обращения (срочность конкретного вопроса). |
| 3 | Оператор | Сотрудник поддержки, который размечает обращения и решает вопросы клиентов. | Не путать с Модератором (проверяет качество) и Руководителем смены (следит за SLA). |
| 4 | Обращение | Запрос от клиента в поддержку, требующий решения. Может поступать из разных каналов. | - |
| 5 | Канал | Источник поступления обращения (например, по телефону, почта, форма на сайте). | - |
| 6 | Обращение "Решено" | Статус обращения, при котором оператор предоставил решение, но клиент еще не подтвердил закрытие или не истек срок авто-закрытия. | Не путать с Обращением "Закрыто" (финальный статус, работа завершена). |
| 7 | Обращение "Закрыто" | Финальный статус обращения, при котором работа по нему полностью завершена и оно не может быть переоткрыто (или переоткрытие требует нового обращения). | Не путать с Обращением "Решено". |
| 8 | Приоритет обращения | Степень срочности обработки конкретного обращения. Влияет на порядок назначения оператору. | Не путать с Уровнем клиента (статус самого клиента). |
| 9 | Модератор | Сотрудник, проверяющий качество ответов оператора и дающий обратную связь. | Не путать с Оператором. |
| 10 | Руководитель смены | Сотрудник, отслеживающий количество тикетов не в SLA и управляющий работой смены. | - |
| 11 | Исполнитель | Сотрудник (оператор), который в данный момент назначен на решение обращения. | Не путать с Автором обращения (клиент, создавший запрос). |
| 12 | Автор обращения | Клиент, который создал обращение в поддержку. | Не путать с Исполнителем. |
| 13 | Сообщение | Текстовая единица коммуникации внутри одного обращения (ответ оператора или клиента). | Не путать с Обращением (весь запрос целиком). |
| 14 | Фидбек | Обратная связь от модератора оператору по качеству ответа. | - |
| 15 | Знания (база знаний) | Источник информации, на который оператор может ссылаться при решении обращения. | - |
| 16 | Разметка обращения | Процесс категоризации или маркировки обращения оператором. | - |
