# Требования: SupportDesk

## 1. Контекст
Сейчас нет клиента, который бы позволял решать оператору обращения из разных каналов в одном месте, что ведет к снижению производительности сотрудников и росту тикетов с просроченным SLA. Модераторы не могут производить качественный контроль ответов сотрудников, а администраторы оценку обращений с просроченным SLA, что ведет к падению CSAT и качества ответов. 

## 2. Бизнес-требования
БТ-1. Снижение тикетов с просроченным SLA с 20% до 10% за пол года.
БТ-2. Повышение метрики CSAT с 4 до 4,5, за 3 месяца.
БТ-3. Снижение критических ошибок саппортов с 10% до 7% за 3 месяца.

## 3. Пользователи и их задачи
Роли: оператор, руководитель смены, клиент
Оператор: размечает обращения, решает вопросы юзеров.
Модератор: проверяет качество ответов оператора и дает фидбек.
Администратор: отслеживает кол-во тикетов не в SLA.
Юзер: пишет в поддержку с проблемами или пожеланиями по сервису.

## 4. Пользовательские требования
ПТ-1. Юзер хочет получать ответ быстрее → связано с БТ-1 и БТ-2.
ПТ-2. Операторы хотят инструмент, который позволит решать обращения из других каналов связи в одном месте → связано с БТ-1
ПТ-3. Модераторы хотят клиент для дачи развернутого фидбека сотрудникам. → связано с БТ-3
ПТ-4. Администраторы хотят, чтобы формировался ежедневный отчет со статистикой по операторам с тикетами не в SLA.

## 5. Функциональные требования
ФТ-1. Система ежедневно формирует отчет с тикетами не в SLA по операторам → связано с ПТ-4
ФТ-2. Система дает выделает отдельные поля для ссылок на знания с ошибками → связано с ПТ-3
ФТ-3. Система объединяет обращения из разных каналов связи и направляет их оператору → связано с ПТ-2
ФТ-4. Система в первую очередь назначает на оператора обращения, которые скоро будут просрочены по SLA → связано с ПТ-1

## 6. Нефункциональные требования
Заполним на уроке 10

## 7. Ограничения

ОГР-1. Данные пользователей должны храниться на серверах в РФ.

## 8. Что НЕ входит в объём
1. На этом этапе не должно быть мобильного приложения.
2. На этом этапе не должно быть интеграций со внешними системами.
3. На этом этапе не должно быть интеграции с AI.
