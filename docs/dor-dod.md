# DoR и DoD проекта SupportDesk

Здесь описаны критерии для взятия задачи в работу и критерии, по которым можно понять, закончена ли задача.

## Definition of Ready - задачу можно брать в спринт, если..

1.	Я как администратор хочу видеть клиент для разбора обращений от пользователей, разбирать обращения будут саппорты. Оценка длительности задачи 1 месяц. 
2.	С помощью клиента должно быть можно производить полный цикл обработки обращений. Обращения должны поступать в клиент из разных каналов связи, учтен расчет SLA по формуле SLA = (Количество тикетов, обработанных в срок / Общее количество тикетов) × 100%.
3.	Зависимостей с внешними системами не выявлено, все будет локально.
4.	На сервере настроить логику доступов и проверки авторизации. (Роли: оператор, Администратор, модератор)
5.	Макеты для интерфейса клиента готовы.
6. При возникновении ошибок в работе клиента должна появляеться плашка с информацией об ошибке и возможность оставить баг репорт для любой роли.

## Definition of Done - задача закончена, если..

1.	Код написан и прошел ревью.
2.	Тесты написаны и проходят.
3.	Задача развернута на тест или проверенна.
4.	Выполнены все критерии приемки.
5.	Документация обновлена.
6.	Нет критических дефектов.
