# SupportDesk

Система для полного цикла разбора обращений от пользователей. Проект создается в рамках обучения професси системного аналитика.

## Что решает?
Нет четкой системы разбора обращений. Простые вопросы могут долго лежать в беклоге без решения, а высококвалифицированный специалист может не добраться до сложных кейсов, на решение, которых ему хватает опыта. Проект позволит упорядочить этот поток обращений, задать четкие правила их разбора и назначения на операторов, чтобы каждый вопрос решался быстро и правильно.

## Структура репозитория
- api/ - фрагменты кода связанные с api 
- db/ - база данных
- diagrams/ - Диаграммы и схемы процессов
- docs/ - требования, голоссарий, договоренности
- src/ - код проекта
